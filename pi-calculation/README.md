# Pi Calculation Project

This project provides a web-based application to calculate the value of π (pi) using various mathematical methods. Users can specify the number of decimal places for π (up to 15) and trigger calculations for different algorithms. The application also displays the time taken for each calculation method.

## Features

- Calculate π using the following methods:
  - Archimedes' Algorithm
  - Madhava's Series
  - Gregory-Leibniz Series
  - Machin's Formula
  - Monte Carlo Method
  - Borwein's Iterative Method
  - Gauss-Legendre Algorithm
  - Chudnovsky Algorithm

- Display the calculated value of π up to 15 decimal places.
- Show the computation time for each method.

## Usage

1. Open `index.html` in a web browser.
2. Enter the desired number of decimal places (up to 15) in the input field.
3. Click on the button corresponding to the method you wish to use for the calculation.
4. The calculated value of π and the time taken for the calculation will be displayed on the webpage.

## Methods Overview

### Archimedes' Algorithm
An ancient method that approximates π by inscribing and circumscribing polygons around a circle.

### Madhava's Series
A series expansion that converges to π, derived from the Taylor series for the arctangent function.

### Gregory-Leibniz Series
A simple series that represents π as an infinite sum, though it converges slowly.

### Machin's Formula
A formula that expresses π in terms of arctangent functions, allowing for faster convergence.

### Monte Carlo Method
A probabilistic method that estimates π by simulating random points in a square that contains a quarter circle.

### Borwein's Iterative Method
An iterative algorithm that converges rapidly to π using a specific sequence.

### Gauss-Legendre Algorithm
A very fast algorithm for calculating π that uses arithmetic-geometric mean.

### Chudnovsky Algorithm
A fast method for calculating π based on Ramanujan's π formulas, known for its rapid convergence.
